## Пояснения

**2.1.** `Ordered_list<T>` использует закрытое наследование от `std::list<T>`: это отношение «реализован через», а не публичное «является». Все изменяющие операции базового списка скрыты от клиента. Вставка всегда находит позицию, сохраняющую неубывающий порядок. `remove` удаляет все равные значения, как метод стандартного списка. Для типа `T` требуются `operator<` и `operator==`.

**2.2.** Когда массив заполнен, ёмкость удваивается. После удаления, если число элементов не превышает четверти ёмкости, она сокращается вдвое, но не ниже 4. Порог 1/4 предотвращает постоянные перераспределения около половины ёмкости. При цикле роста суммарное число копирований ограничено геометрическим рядом O(m); при сокращениях между двумя перераспределениями проходит достаточно операций. Поэтому любые `m` операций занимают O(m) суммарно, то есть O(1) амортизированно на операцию. Само перераспределение занимает O(n). Массив шаблонный, но в этом примере предполагается тип `T` с конструктором по умолчанию и присваиванием.

**2.3.** Каждый узел содержит три ссылки `next`: по ФИО, дате рождения и номеру группы. Для каждой цепочки фиктивная голова и последний узел замыкают кольцо. Вставка находит место в каждой цепочке; вывод по любому ключу проходит только нужную цепочку ровно один раз, O(n). Дата хранится в ISO-формате `YYYY-MM-DD`, что позволяет сравнивать даты как строки. При равенстве ключа дополнительные поля и порядковый номер обеспечивают определённый порядок.

**3.1.** Узлы адресуются целочисленными индексами. Поле `next` неиспользуемой ячейки служит ссылкой в стеке свободных ячеек. Вставка и удаление по известному индексу O(1), поиск O(n). При заполнении массив удваивается; поэтому вставка O(1) амортизированно, а отдельное расширение O(n). Индексы сохраняются при расширении, но индекс удалённого элемента нельзя использовать повторно: ячейка может быть выдана новому элементу. Память — один массив узлов и конечное число скалярных полей.

**3.2.** На каждом проходе все ещё не отсортированные элементы переносятся во временный стек, запоминается максимум, затем все, кроме одной копии максимума, переносятся обратно. Выбранные максимумы остаются на дне временного стека. После последнего прохода извлечение из временного стека даёт возрастающий порядок. Используются только `Push`, `Pop`, `Create`, `Empty` и счётчики. Количество операций стека равно O(n²); дополнительная память O(n).

**3.3.** Файл содержит `n`, затем `n` различных целых чисел. Выводятся однобазовые индексы ближайшего справа большего элемента, `0` при его отсутствии. Стек хранит индексы, для которых ответ ещё не найден; значения по этим индексам убывают. Каждый индекс кладётся в стек один раз и извлекается не более одного раза, всего O(n) операций и O(n) памяти. Это также амортизационное доказательство: стоимость извлечений оплачивается предшествующими добавлениями.
